YouTube setup

One-time job of about ten minutes. After that, connecting is just a Google login.
{% if yt_secret_present %}

Client secret is in place. {% if not rows[0].account_name %}Press Connect above and sign in with the channel's Google account.{% else %}Replace it below only if you create a new OAuth client in Google Cloud.{% endif %}

{{ yt_secret_path }}

{% else %}
  1. Open console.cloud.google.com/projectcreate, name it anything (Repurposer), Create.
  2. APIs and Services → Library → search YouTube Data API v3 → Enable.
  3. APIs and Services → OAuth consent screen → External → app name Repurposer, your email for both contact fields → Save. Under Audience, press Publish app. Skip this and the login expires after seven days.
  4. APIs and Services → Credentials → Create credentials → OAuth client ID → type Desktop app → Create → Download JSON.
  5. Drop that JSON below, then press Connect. Google shows an "unverified app" screen: Advanced → Go to Repurposer.

New Google projects can only upload as private until YouTube's API compliance audit is approved. Apply at the YouTube API services form once the first upload works.

{% endif %}
