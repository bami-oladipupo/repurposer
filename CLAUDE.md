# Repurpose Content

Owner: Bami. Purpose: repurpose long-form content into platform-ready pieces.

## Conventions
- Inputs go in `inputs/`, date-first names (`YYYY-MM-DD description.ext`).
- Outputs go in `outputs/`, grouped by source or platform.
- Specs for tools live in `specs/` using the standard build-spec template (current state, problem, changes in build order, acceptance criteria, open questions).
- Notes and decisions in `notes/`.
- No em dashes in written output. Action-first summaries. Tables for comparisons.
- Errors in any scripts or pipelines must surface, never be swallowed.
